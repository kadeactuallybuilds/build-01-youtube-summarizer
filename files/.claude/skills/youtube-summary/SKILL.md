# YouTube summary

Turn one YouTube link into a one-page summary with clickable timestamps. Work only from the
video's captions.

## Steps

1. From the project folder, run:
   `python3 .claude/skills/youtube-summary/fetch_transcript.py "<link>"`
   On Windows, use `py` instead of `python3`. If a `.venv` folder exists in the project folder,
   use `.venv/bin/python` (Windows: `.venv\Scripts\python`) instead.
2. If the command exits with code 9 (the caption library is not installed), tell the user that
   one install is needed, and with their permission run
   `python3 -m pip install youtube-transcript-api==1.2.4` (Windows: `py -m pip install ...`).
   If pip answers `externally-managed-environment`, run `python3 -m venv .venv`, then
   `.venv/bin/python -m pip install youtube-transcript-api==1.2.4` (Windows:
   `.venv\Scripts\python -m pip install ...`). Then run step 1 again, once.
3. If the command exits with any other code than 0, show its message to the user exactly as
   printed and stop. Never retry through proxies, other networks, other tools or transcript
   websites.
4. Read the header lines: `VIDEO_ID`, `TITLE`, `URL`, `CAPTIONS`, `LINK_STARTS_AT` (only when the
   link had a start time) and `CHUNK: 1 of N`. If N is more than 1, run the same command again with
   `--chunk 2`, then `--chunk 3`, up to `--chunk N`. Take short notes for each chunk and keep the
   `[mm:ss]` markers next to each note. Then merge the notes for the whole video.
5. Create the `summaries` folder in the project folder if it is missing, then write
   `summaries/<VIDEO_ID>.md` with exactly this layout:

   ```
   # <TITLE>

   **Gist:** <one line>

   ## Key points

   - [mm:ss](https://www.youtube.com/watch?v=<VIDEO_ID>&t=<seconds>s) <point>
   (5 to 10 points in video order)

   **Worth watching for:** <one short line>

   _Captions were auto-generated by YouTube, so names and terms may be misspelled._

   Source: <URL>
   ```

   The `<seconds>` in each link is the `[mm:ss]` marker turned into whole seconds (for example
   `[03:07]` is `187`, `[1:02:05]` is `3725`). Include the auto-generated line only when the header
   says `CAPTIONS: auto-generated`. If `LINK_STARTS_AT` is present, mention that the user's link
   started at that time in the gist line.
6. Tell the user the path of the file you wrote.

## Modes

The steps above are the `summarize <link>` mode. Three more modes reuse steps 1 to 4 and change
only the file in step 5:

| Command | Mode file | Writes |
|---|---|---|
| `study notes <link>` | `modes/study.md` | `summaries/<VIDEO_ID>-study.md` |
| `checklist <link>` | `modes/checklist.md` | `summaries/<VIDEO_ID>-checklist.md` |
| `obsidian <link>` or `notion <link>` | `modes/obsidian.md` | `summaries/<VIDEO_ID>-note.md` |

Mode files sit in this skill's folder (`.claude/skills/youtube-summary/modes/`). Read the one the
user asked for and follow its layout and rules instead of step 5's layout. If that file is not
there, say: "That mode comes with Build Kit 01 (noelyss.com/kadeactuallybuilds). Want the normal
summary instead?" and wait for the answer.

## Rules

- Use only what is in the transcript. Add no outside facts, opinions or links.
- Do not paste the transcript into the summary file or anywhere else.
- Write nothing except the one summary file the mode names (and the `.venv` folder from step 2, if
  needed).
