# The Ultimate Knowledge Base: Bring YouTube Into Your AI Second Brain

**Gist:** The creator packages their ~200-video YouTube channel as an Open Knowledge Format (OKF) knowledge base for AI agents, explains how it was built, and shares skills to build one for any channel.

- [00:00](https://www.youtube.com/watch?v=8JWhwhxWtJw&t=0s) OKF is presented as a standard for agent-to-knowledge-base access, comparable to MCP for tools and A2A for agent-to-agent, building on the Karpathy LLM Wiki idea.
- [01:02](https://www.youtube.com/watch?v=8JWhwhxWtJw&t=62s) Demo in Claude Code: complex questions (end-to-end AI coding workflow, when RAG still matters, how the second brain works) get answers that cite specific videos with timestamps.

- [07:41](https://www.youtube.com/watch?v=8JWhwhxWtJw&t=461s) Build pipeline step 1: pull every video's transcript as timestamped markdown into a raw folder so answers can cite exact sources.
- [08:43](https://www.youtube.com/watch?v=8JWhwhxWtJw&t=523s) Step 2, "canonicalization": find the recurring concepts and entities across all transcripts, give each its own file, and link each back to its source videos.
